How it works
1

Create a Bitcoin Transaction

Send a policy-valid Bitcoin transaction (self-transfer, using a P2WPKH Native SegWit address (starts with bc1q)) using the address derived from your Nostr key.

2

Publish Nostr Events

Create and publish Name, Connection, and Metadata events signed with your Nostr key, then publish an anchor event referencing the naddr addresses of those events.

3

Enjoy!

Now you have a human-readable, memorable DNN ID that can be used socially or to load your websites.

DNN: Decentralized Naming Network

A Bitcoin-anchored decentralized naming system powered by Nostr

DNN Node

Version 0.1.0 (Alpha)

Docs

Key Features

Bitcoin Anchored

Secured by Bitcoin blocks, without adding any data to it, making names immutable, time-ordered, and resistant to spam or takeover.

Nostr Powered

Leverages an ever-growing network of decentralized relays to give you full control over names, records, and metadata while staying censorship-resistant.

Censorship-Resistant

Once anchored, names cannot be revoked, seized, or silenced by any central authority.

ICANN:DNS Alternative

Human-readable names that can resolve in compatible browsers, apps, and future DNS-like systems without central control.

ICANN:IANA Alternative (Future)

A future path toward decentralized IP addressing and routing without centralized allocation authorities.

Self-Sovereign

You own your name, keys, and identity—no registrars, renewals, or permission required.

Social ID

A recognizable identity that replaces long npubs, making discovery easier and impersonation far harder.

Cost-Effective

Register once for pennies with no renewals, subscriptions, or recurring fees.

Scalable

Human-readable, memorable names that remain usable thousands of years into the future.

Infinite Websites

Your name acts like a personal TLD, letting you host unlimited websites and services under one identity.

Trustless SSL

Self-sign certificates for your names without relying on a central authority, while still maintaining security and integrity.
